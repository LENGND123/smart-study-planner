# 🚀 Smart Study Planner

A modern productivity dashboard built with **React + Tailwind CSS** to help students manage deadlines efficiently.

## 🌍 Live Demo
👉 https://smart-study-planner-roan.vercel.app

## 📌 Features

- 📅 Deadline-based smart priority system
- 📊 Dashboard analytics (Total / Pending / Completed)
- 📈 Animated progress bar
- 🏷 Category filtering
- 🗑 Clear completed tasks
- 💾 LocalStorage persistence
- 🌙 Modern dark SaaS-style UI
- 📱 Fully responsive design

## 🛠 Tech Stack

- React (Vite)
- Tailwind CSS
- JavaScript (ES6+)
- Vercel (Deployment)

## 🚀 Installation (Run Locally)

```bash
git clone https://github.com/LENGND123/smart-study-planner.git

npm install
npm run dev
```
